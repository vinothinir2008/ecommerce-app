# E-Commerce Web Application

Full-stack e-commerce app built for the Thiranex internship.

**Live:** https://ecommerce-app-r117.onrender.com

## Features
- User registration and login (JWT authentication)
- Role-based access (Admin / User)
- Admin: add, edit, delete products; view all orders and update order status
- Product catalog with search
- Cart, checkout and order history
- Responsive design

## Tech Stack
HTML, CSS, JavaScript | Node.js, Express | MongoDB (Mongoose) | Render

## Run locally
1. npm install
2. Create .env with MONGO_URI, JWT_SECRET, ADMIN_KEY
3. node server.js
